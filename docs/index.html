NimDrake

DuckDB, the in-process analytical SQL engine, from Nim.

nimble install nimdrake

API reference Cookbook GitHub

NimDrake is a Nim binding for DuckDB, the embedded analytical SQL database. There is no server to run — DuckDB lives inside your process and is tuned for large scans, aggregations, and joins over CSV, Parquet, and Arrow input.

  • Zero-copy reads — results are typed views over DuckDB's own columnar buffers. Primitives are never copied on read.
  • Layered API — a high-level con.execute for everyday work, and a low-level streaming Vector[kt] layer.
  • Full type system — all DuckDB types mapped, including List, Struct, Map, Decimal, UUID, and 128-bit integers, exposed via zero-copy typed container views.
  • UDFs — register Nim procs and {.closure.} iterators as scalar, aggregate, and table functions.
  • Arrow export — optional integration streams results as Arrow record batches via narrow.

Quick start

import nimdrake

let db = newDatabase()       # in-memory
let con = db.connect()

let r = con.execute("""
  SELECT i, i * i AS sq
  FROM generate_series(1, 5) AS t(i)
""")
echo r

Or iterate chunks with zero-copy column access: 

for chunk in r:
  let sq = chunk.vector(1).bindAs DuckType.BigInt
  echo sq[0]   # 1

Streaming results

For large result sets, execute the statement in streaming mode and consume one chunk at a time. Iterating a million rows never materializes the whole thing. 

let stmt = con.newStatement(
  "SELECT i FROM generate_series(1, 1_000_000) AS t(i)")

var count = 0
for chunk in con.executeStreaming(stmt):
  let v = chunk.vector(0).bindAs DuckType.BigInt
  count += v.len

echo "Total rows: ", count    # Total rows: 1000000

Prepared statements

Prepare once, execute many times with different parameters: 

con.execute("CREATE TABLE people (id BIGINT, name VARCHAR, active BOOLEAN)")
let stmt = con.newStatement("INSERT INTO people VALUES (?, ?, ?)")
con.executeMaterialized(stmt, (int64(1), "Alice", true))
con.executeMaterialized(stmt, (int64(2), "Bob", false))
echo con.execute("SELECT * FROM people ORDER BY id")

User-defined functions

Write an ordinary Nim proc, register it, and call it from SQL: 

proc multiply(a, b: int64): int64 = a * b
con.registerScalar(multiply)

let r = con.execute("SELECT multiply(3::BIGINT, 7::BIGINT)")
echo r    # 21
